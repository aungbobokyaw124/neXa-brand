# MILESTONE 001 — neXa Original Brand Foundation

**Date:** 2026-08-31  
**Status:** Active

## Locked Brand Definition

**Brand Name:** neXa  
**Meaning:** Next-Generation Technology Ecosystem  
**Positioning:** AI-powered technology for the next generation.  
**Short Tagline:** Build Beyond.

## Foundation Decisions

1. neXa is not restricted to AI-only products.
2. AI is a core technology layer within a broader technology ecosystem.
3. The master visual identity is vector-first.
4. SVG is the canonical logo source format.
5. The repository is the brand source of truth.
6. Trademark status is not claimed until the appropriate legal process confirms it.
